# Telegram Consultant Bot

Готовый шаблон Telegram-бота для приветствия и первичной консультации клиентов. Поведение целиком описывается в YAML-файле: вы задаёте приветствие, меню разделов, ответы на частые вопросы и правила сбора заявок без изменений в коде.

## Возможности

- Стартовое приветствие с клавиатурой быстрых вариантов.
- Меню разделов «клиника под ключ», «как мы работаем», FAQ и форма заявки.
- Навигация по готовому дереву ответов без генерации текста.
- Настраиваемые команды `/start`, `/menu`, `/help`, `/stop`.
- Фиксированная форма «Оставить заявку»: пользователь присылает одно сообщение, бот возвращает резюме и клавиатуру для дальнейших шагов.
- Отправка уведомлений о новых заявках в выбранные чаты Telegram.
- Удобная конфигурация через `config/bot_config.yaml`.

## Быстрый старт

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Получите токен у [@BotFather](https://t.me/BotFather) и сохраните его в файле `.env`:

   ```bash
   cp .env.example .env
   # откройте .env в любом редакторе и вставьте токен вместо заглушки
   ```

   При запуске файл будет автоматически загружен и переменная `TELEGRAM_BOT_TOKEN` окажется в окружении.

   > Альтернатива: можно передать токен напрямую в командной строке через ключ `--token`.
   >
   > ```bash
   > python -m src.bot.main --config config/bot_config.yaml --token "1234567890:ABCDEF"
   > ```

3. Настройте, куда отправлять новые заявки. Укажите ID менеджера или группы в переменной `TELEGRAM_MANAGER_CHAT_ID` в файле `.env`. Узнать ID можно через [@userinfobot](https://t.me/userinfobot) или по логам после первого обращения.

   Если получателей несколько, добавьте их в массив `bot.notify_chat_ids` файла `config/bot_config.yaml` (принимает числа или плейсхолдеры `${ENV_NAME}`).

4. Запустите бота:

   ```bash
   python -m src.bot.main --config config/bot_config.yaml
   ```

## Настройка поведения

Все тексты и логика берутся из файла `config/bot_config.yaml`. Например:

```yaml
bot:
  name: "ClinicGuru"
  farewell: "Буду рад помочь с запуском вашей клиники!"
  notify_chat_ids:
    - "${TELEGRAM_MANAGER_CHAT_ID}"

script:
  start_node: "welcome"
  fallback_text: "Пожалуйста, выберите вариант из списка ниже."
  nodes:
    - id: "welcome"
      text: |
        Добро пожаловать! 👋
        Мы помогаем инвесторам и владельцам открыть стоматологическую клинику под ключ — от идеи и бизнес-плана до лицензий, оборудования и сервисного обслуживания.

        С нами вы экономите время, бюджет и избегаете типичных ошибок на старте.

        Выберите раздел, который сейчас важнее всего:
      options:
        - label: "Что такое «клиника под ключ»"
          next: "turnkey_overview"
        - label: "Как мы работаем"
          next: "workflow"
        - label: "Частые вопросы"
          next: "faq"
        - label: "Оставить заявку"
          next: "lead_capture"
    - id: "lead_capture"
      text: |
        Отлично, давайте сделаем первый шаг ✅

        Пожалуйста, отправьте одним сообщением:

        Город

        ФИО

        Номер телефона

        Что вас интересует?
        (например: открытие клиники с нуля, расширение, проектирование, лицензирование, оснащение и т.д.)

        Как только получим эти данные, наш специалист свяжется с вами, чтобы обсудить детали и ответить на вопросы.
      options:
        - label: "Вернуться в начало"
          next: "welcome"
      capture:
        type: "lead_form"
        next_node: "welcome"
```

- `bot.name` и `bot.farewell` — имя и прощальное сообщение бота.
- `bot.notify_chat_ids` — список ID чатов, куда прилетит уведомление о заявке. Можно указывать числа напрямую или плейсхолдеры `${ENV_NAME}` для подстановки переменных окружения.
- `script.start_node` — узел, который отправляется после `/start` или `/menu`.
- `script.nodes` — массив узлов сценария. Каждый узел содержит `text` и набор `options`.
- `options[].label` — подпись кнопки, которую увидит пользователь.
- `options[].next` — идентификатор узла, который откроется после нажатия на кнопку.
- `fallback_text` — что бот скажет, если сообщение не совпадает ни с одним вариантом текущего узла.
- `capture` — необязательный блок с особой логикой. Тип `lead_form` просит пользователя прислать одно сообщение с данными, возвращает резюме и отправляет его менеджеру. `next_node` задаёт, куда вернётся пользователь после отправки.

## Расширение

- Добавьте новые узлы и варианты в `script.nodes`, чтобы расширить сценарий.
- Создайте несколько YAML-конфигураций для разных направлений бизнеса и переключайте их параметром `--config`.
- При необходимости расширьте обработчики в `src/bot/handlers.py`, чтобы реагировать на дополнительные команды или события Telegram API.
- Реализуйте собственные типы `capture`, если нужно иное поведение при свободном вводе.
