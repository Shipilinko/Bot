# Telegram Consultation Bot Skeleton

Базовый Telegram-бот, который помогает консультировать пользователей и легко расширяется новыми ответами.

## Возможности

- Команда `/start` отправляет приветствие с описанием целей бота.
- Команда `/help` показывает доступные команды и примеры вопросов.
- Текстовые сообщения обрабатываются простой базой знаний, которую можно расширять.

## Требования

- Python 3.10+
- Установленный [poetry](https://python-poetry.org) или `pip`
- Токен Telegram-бота (получается у [BotFather](https://core.telegram.org/bots#botfather))

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

1. Создайте бота через BotFather и получите токен.
2. Установите переменную окружения с токеном:

   ```bash
   export TELEGRAM_BOT_TOKEN="<ваш токен>"
   ```

3. (Опционально) Отредактируйте базу знаний в `bot.py`:

   - `ConsultationKnowledgeBase.exact_matches` — точные фразы и ответы на них.
   - `ConsultationKnowledgeBase.keyword_matches` — ключевые слова и реакции.
   - `ConsultationKnowledgeBase.default_response` — ответ по умолчанию.

4. Запустите бота:

   ```bash
   python bot.py
   ```

Бот начнет работу и будет получать обновления методом polling. Остановить бота можно сочетанием клавиш `Ctrl+C`.

## Как расширять ответы

1. Добавьте новые ключи и ответы в `exact_matches`, если ожидается конкретная формулировка запроса.
2. Для гибких сценариев используйте `keyword_matches` — бот ищет подстроки в сообщении.
3. Расширьте `default_response`, чтобы подсказать пользователю, как сформулировать вопрос или связаться с оператором.
4. При необходимости вы можете заменить `ConsultationKnowledgeBase.make_response` собственной логикой (например, подключить ИИ или
   интегрировать внешнюю базу данных).

## Разработка

- При добавлении новых обработчиков изучите документацию [python-telegram-bot](https://docs.python-telegram-bot.org/en/stable/).
- Следите за секретами: не храните токен в коде и не коммитьте `.env` файлы.
